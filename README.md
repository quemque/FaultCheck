# FaultCheck
Скачать репозиторий 
```bash
git clone https://github.com/quemque/FaultCheck
```
# backend
```bash
cd faultcheck
```
## установить зависимости
```bash
uv sync
```
## Обучение моделей и поднятие fastapi
```bash
uv run train

```
```bash
uv run serve
```
