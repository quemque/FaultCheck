# FaultCheck

# Скачать репозиторий

```bash
git clone https://github.com/quemque/FaultCheck
```

# backend

```bash
cd backend
```

## Установка зависимостей

```bash
uv sync
```

## Обучение моделей

```bash
uv run train
```

## Запуск fastapi

```bash
uv run serve
```

# frontend

```bash
cd frontend
```

## Установка зависимостей

```bash
bun i
```

## Запуск проекта(dev)

```bash
bun run dev
```
